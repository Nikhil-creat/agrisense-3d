What this actually does

Problem

Farmers spot crop disease late, and generic treatment lookups don't verify whether the advice matches what's actually on the leaf.

Approach

Real photo → MobileNet (a pretrained CNN, loaded via TensorFlow.js) turns the leaf into a 1024-number embedding. That embedding is compared by cosine similarity to a few reference embeddings per disease class — a real few-shot transfer-learning technique, not a lookup table. The agent then retrieves treatment text with TF-IDF, verifies the retrieved source actually names the diagnosed disease, and retries with a narrower query if it doesn't, before acting on the plot.

Honest limits

The built-in reference photos are a small demo set so the app works out of the box; classification quality depends entirely on the reference photos loaded. Use "Calibrate with real photos" to upload your own labelled examples per class — more and cleaner references directly improve accuracy. For production accuracy, train a dedicated CNN on a labelled dataset such as PlantVillage and serve it from the included FastAPI backend instead of doing few-shot matching in the browser (see README).
